The set

Two pieces, drawn together

The chair and the table share the same angled legs and soft curves, so they read as one set in a room.

The table

A boat-shaped top on four tapered legs. A cut-out brace at each leg carries the curve of the chairs into the table.

The chair

The back and arms are one open, curved frame. The seat is upholstered, and the legs splay out from the seat rail.

Layout

Four chairs, two a side

The standard layout seats four, with two chairs on each long side of the table. A six-chair set is also made.
